# AWS Lambda

Lambda is serverless, event-driven compute service that allows you to run code without provisioning or managing servers. 

## Example: Serverlss Go application run on AWS Lambda

To create a serverless Go application on AWS Lambda, you'll need to write your Go code, compile it, and then deploy it to AWS Lambda using the AWS Management Console, the AWS CLI, or the Serverless Framework. 

The Serverless Framework simplifies deployment by managing infrastructure as code (IaC).
