# Langflow

Langflow is a tool to build and deploy AI agents and MCP servers.

Langflow is a low-code or no-code visual framework designed for building, prototyping, and deploying AI applications, specifically focused on agentic AI and Retrieval-Augmented Generation (RAG) workflows. It functions as a graphical user interface (GUI) for LangChain, allowing users to connect language models, data sources, and tools through a drag-and-drop.

Low-Code/No-Code AI Platform: It empowers users to build complex LLM applications without extensive coding.

Agentic Workflow Builder: Used to design autonomous agents, connect them to tools (like SQL or search), and orchestrate their behavior.

RAG System Builder: Utilized for building applications that connect LLMs to external data sources for document retrieval and analysis.

Visual Programming: Provides a flowchart-like interface (nodes and edges) to represent and test LLM component interactions visually.

Orchestration Framework: Enables linking prompt templates, LLMs, and memory to manage the sequence and execution of AI tasks.
