# GitHub Copilot

GitHub Copilot is an AI coding assistant developed by GitHub and OpenAI.

Code Completions: It offers auto-complete-style suggestions for single lines or entire functions as a developer types, or based on natural language comments describing desired functionality.

Chat Assistance: Users can interact with a chat interface within their Integrated Development Environment (IDE) or on GitHub.com to troubleshoot bugs, craft new features, or ask general coding questions.

Code Explanation and Refactoring: It can explain existing code snippets or suggest ways to refactor and simplify code without the user having to switch context to an external application.

Agents: The advanced agent mode allows for more autonomous actions, such as automatically generating a draft pull request, creating commits, and performing code analysis based on an assigned issue.
