# Autonomous Coding and Development Agents

OpenCode: An AI coding agent designed for the terminal that offers high privacy.
SERA (Soft-verified Efficient Repository Agents): A new, fast, open-coding agent family designed to handle repository-level tasks, compatible with Claude Code.
MetaGPT: Simulates an entire software company, with specialized agents for different roles (CEO, PM, Engineer).
GPT Engineer: An agent that generates codebases from prompts.
Cline: An open-source agent giving developers access to frontier models.

AI agents decide what to do next, sequence their own tasks, call external tools, evaluate intermediate results, and adjust their approach as needed.
