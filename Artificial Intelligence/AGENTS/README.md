# Agents for Artificial Intelligence (AI)

Agents are systems that independently accomplish tasks on your behalf.

An agent takes input (a user query or system event), determines what action to take based on the context, uses a tool or chain to complete the task, and then sends the result back to the user or system.

Agents are helpful in situations where the next step is not predefined (for instance, a chat application that responds to various kinds of questions), or when the application needs to make decisions rather than just executing a series of actions, or when integrating several workflows or tools in a system.

When creating LLM agents, an LLM acts as the controller that manages a series of actions required to finish a task or user request.

Tools are functions or external resources that an agent can utilize to interact with its environment.

Once a decision is made, the AI agent can execute the required action.

A workflow is a sequence of steps that must be executed to meet the user’s task.

What are AI agents?

AI agents are software programs that use AI to accomplish tasks and pursue objectives on behalf of users.

AI agents work by using machine learning models and other tools to respond to questions and perform tasks.

How do LLM agents work?

User queries are processed step-by-step by LLM agents. They start by receiving the user's request and analyzing it to identify the main points, such as the action required or the type of information requested.

## Steps to create an AI agent

1. Define the task

AI agents are able to generate a list of tasks, when implementing the required task. 

2. Populate the tool repository

The tools your agent needs are available in the tool repository.

3. Build the AI agent framework

A framework for creating AI agents that provides tools for creating AI agents.

4. Give the complete task to the AI agent

AI agents can execute code, search, and compute using a variety of tools.
