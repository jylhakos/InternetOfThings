# Feature Engineering Output Directory

This directory contains the **output artifacts** generated by feature engineering processes.

## 📁 Directory Structure

```
feature_engineering/
├── extracted_features/     # Feature vectors and representations
│   ├── cnn_features/       # CNN-extracted features (.npy files)
│   ├── rnn_features/       # RNN/LSTM features (.npy files)
│   ├── transformer_features/ # BERT/Transformer features (.npy files)
│   ├── autoencoder_features/ # Autoencoder latent representations
│   └── transfer_features/   # Transfer learning features
├── processed_datasets/     # Preprocessed and augmented datasets
│   ├── tokenized_text/     # Tokenized text datasets
│   ├── normalized_images/  # Normalized image datasets
│   └── feature_matrices/   # Feature matrices ready for ML
├── visualizations/         # Feature visualization outputs
│   ├── feature_plots/      # 2D/3D feature space plots
│   ├── attention_maps/     # Attention weight visualizations
│   └── dimensionality_reduction/ # t-SNE, PCA plots
└── reports/               # Feature analysis reports
    ├── feature_importance/ # Feature importance analysis
    └── correlation_analysis/ # Feature correlation matrices
```

The **feature engineering** process involves:

1. **Feature Extraction**: Running feature engineering scripts from `src/feature_engineering/`
2. **Feature Storage**: Saving extracted features as `.npy` files in `extracted_features/`  
3. **Dataset Processing**: Creating processed datasets in `processed_datasets/`
4. **Visualization**: Generating feature plots and analysis in `visualizations/`
5. **Analysis**: Creating feature analysis reports in `reports/`

## Usage

Feature engineering scripts automatically save their outputs into this directory.

```bash
# Extract CNN features
python src/feature_engineering/cnn_feature_engineering.py --output-dir feature_engineering/

# Extract RNN features
python src/feature_engineering/rnn_feature_engineering.py --output-dir feature_engineering/

# Extract Transformer features
python src/feature_engineering/transformer_feature_engineering.py --output-dir feature_engineering/
```

## Feature File Formats

- **Features**: NumPy arrays (`.npy`) with shape `(n_samples, n_features)`
- **Labels**: NumPy arrays (`.npy`) with shape `(n_samples,)`
- **Metadata**: JSON files (`.json`) with feature descriptions
- **Visualizations**: PNG/PDF plots of feature spaces
