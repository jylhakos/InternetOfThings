# Agent2Agent (A2A)

The Agent2Agent (A2A) protocol is an open-source, vendor-neutral communication protocol designed to enable different AI agents to communicate, collaborate, and exchange information with each other, regardless of the framework (like LangChain, AutoGen, or LlamaIndex)

A2A is a "universal translator" or messaging standard (using HTTPS/SSE) that acts as a connector between agents.
